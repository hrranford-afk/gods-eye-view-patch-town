# Prompt for ChatGPT: Round Table Kingdom art pack 3 (18 Nov 2026)

Written by the game session for Harry to paste into ChatGPT.

The game now plays a whole match on a practice table: both camps are built by toy mice, a Marble Lobber knocks single planks off walls, and three rounds are fought over the flag hill. The models are clean but plain. Your concept pictures look hand-painted; ours look like tidy toy blocks. This pack is to close that gap. Please make three things.

**Part 1: hand-painted texture tiles (the most useful part)**

The game paints every model from small square texture tiles. Please make each of these as its own square picture, 1024 × 1024, seamless (the left edge must match the right, the top must match the bottom), lit flat with no cast shadows and no highlights from one side, seen straight on:

1. Plain wood planks, warm, with brushy grain and soft worn edges between planks.
2. The same planks painted blue, with the paint chipped and rubbed so wood shows through at edges.
3. The same planks painted red, chipped the same way.
4. Rusty tin sheet with rivets and a few dents, orange-brown with grey bare patches.
5. Canvas cloth, cream, with a visible weave and a few stitched seams.
6. Rope wound in rows, seen from the side.
7. Table-top grass and moss with tiny daisies, soft and painterly.
8. Mouse fur, three small swatches side by side in one tile: warm brown, grey, cream.

Style for all: thick visible brush strokes, slightly uneven, like a painted wooden miniature. Not photographic. The same warm colour family as your concept pictures. Blue is a strong cornflower blue; red is a brick red.

**Part 2: character sheets for the three mice**

One picture per team, plain pale background, the same mouse shown four times in a row at the same size: front, side, back, and three-quarter. Standing straight, arms slightly out, so a modeller can copy it. Chunky toy proportions: big head, big round ears, short body, short legs.

- Blue archer: floppy blue hat with goggles on the brim and one white feather, short blue cape, a toy crossbow, a quiver of cork-tipped bolts.
- Red scrapper: dented tin helmet, red scarf, a big cog in one hand, a patched sack of scrap on the back.
- Green builder: yellow miner's helmet with a lamp, green scarf, a big wooden mallet, a bundle of planks and rope on the back.

Friendly faces with large eyes. Toy weapons only. Our own characters: no likeness to any existing film, book, game or brand.

**Part 3: the cards, set 2b (two changes only)**

Keep everything in set 2 as it is, and rebuild the pack with the same code and the same checks, plus:

1. Redraw BLUE BASE. The tower does not read as a tower: it looks like a block with scribbles. Make it a clear tall watchtower: four splayed legs with a cross brace, a boxed lookout platform with a rail, a pointed roof, a ladder up one side, and one large feather flag flying to the right. Tall and narrow, a very different outline from every other card.
2. Add an optional colour version of all six, as a second folder `cards_A6_colour/`. The black artwork stays exactly the same. Add one flat, strong colour per card as a thick band just inside the border and as a fill behind the emblem: World Anchor purple, Blue Base blue, Red Base red, Capture Flag yellow, Hill green, Build Camp orange. Choose the six so that they are also clearly different in brightness when printed in grey. Give the exact colour values in the manifest. The black-and-white folder must still be there and must still pass on its own.

Also thicken the top and bottom border of CAPTURE FLAG so that it is as heavy as its sides.

Re-run your similarity tables for both the black-and-white and the colour versions (for colour, compare the grey versions and also say how far apart the six colours are).
