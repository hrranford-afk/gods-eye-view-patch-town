# GIFT T1: page picture fixes (T1a) and later items

One line per item.

1. THE CREAM SHAPE (fixed): it was a gull (flat 2 m quad, MeshBasic) drawn a few metres from the zoomed-in camera; physical.js hid near gulls but islands_look.html reset `visible` every frame, so at render time gulls as near as 4 m were still drawn (369 bad draws in 54 frames, found by hooking onBeforeRender). Now the page's own gull loop hides any gull within 60 m on gift pages only (default page untouched, hash 8d962c0c, 88,790 triangles); test `tests/t1a-test.js` section 1 (render-time layer check plus pixel check).
2. MOIRE GRAIN (fixed by construction, measured in software GL): the post pass now uses a sin-free hash (Hoskins) on whole buffer pixels and fades the grain to nothing when the browser stretches the canvas by a non-integer factor (iPad: device pixel ratio 2, render 1.5 = 1.33x, grain off; exact 2x keeps it); interleaved gradient noise was measured and rejected (spectral line 131x the floor against 9.6 for the hash). Software GL cannot reproduce the iPad beat itself (the old hash measured as white noise there), so the test (`tests/t1a-test.js` section 2, FFT of a flat patch plus the stretch uniform) proves the new grain is white and switches off where stretched. Default page hash 8d962c0c and 88,790 triangles unchanged.
3. SKY STREAKS AND BANDING (fixed, measured): the post pass now ends in a triangular dither of one 8-bit level (half strength where the canvas is stretched), the no-post dome dithers itself, and the cirrus streak term in `weather.js` (and the rain curtain streak term in `islands_look.html`) is warped with noise so the lines wander and break; on a stretched iPad-like screen the flat run in a sky gradient fell from 5.23 to 2.52 rows and the streak residual from 0.57 to 0.43 levels (worst row 2.60 to 2.19), seen in the before and after shots as shorter, broken wisps instead of ruled lines (some faint long wisps remain); cost: no new passes, no new draws, triangles and draw calls unchanged, cost ladder run and page smoke on ipad, desktop and radeon: 44 passed, 0 failed; `tests/t1a-test.js` section 3.
