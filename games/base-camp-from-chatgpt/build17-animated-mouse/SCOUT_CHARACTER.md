# Build 16 — Stop-motion-inspired Backpack Mouse (actual game model)

**This replaces the scout mesh inside the original Three.js Base Camp.** Not concept artwork, a sprite, a video or a new game.

New: shared procedural felt fibres and canvas weave, parchment exploration map in the paw, sculpted cheek clumps, inner-ear rims, tunic, boot soles and laces, compass insignia, detailed pack. Build 15 animated goggles, ears, tail, scarf, face, and lantern are retained.

Technical: the three 128×128 procedural textures are made once and reused; geometry is shared by names; there are no real-time fur strands or separate shadow-casting character lights.

Existing residents, autosave, camera/AR, practice room, building, battles, cable cars and ceiling rigging remain. First resident of each camp uses the scout. The game still requires three.js r128 from cdnjs (unchanged from prior versions).

To see him: Play (falls back to practice room without AR), or More → Practice room. For a visual without running the game, see the included **offline reconstructed geometry previews**; these are *not* captures from the game engine.
